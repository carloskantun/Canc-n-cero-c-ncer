# Carpeta de imágenes

Aquí van los archivos con los nombres exactos que pide `/content/sitio.json` y el
documento `docs/02-imagenes-codex.md` (prompts, tamaños y reglas de estilo).

Mientras un archivo no exista, el sitio muestra automáticamente un espacio de
color de marca con el nombre de la imagen escrito encima — así se ve qué falta
sin que la página se rompa. En cuanto subas el archivo con el nombre correcto,
la imagen real reemplaza el espacio, sin tocar código.
